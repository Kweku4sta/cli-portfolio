# 🌟 Forster Portfolio (4sta)

A terminal-based interactive developer portfolio built with React Ink.  
Experience my journey right inside your terminal — built purely for fun, creativity, and a love for coding that feels alive.

## Features
- Beautiful terminal/CLI-style portfolio interface  
- Smooth navigation with arrow keys  
- Expandable and collapsible sections  
- Lightweight and fully interactive  
- Keyboard shortcuts for quick access and control

## Prerequisites
Before installation, make sure you have Node.js version 16 or later installed.  
👉 [Download Node.js here](https://nodejs.org)  
To verify installation, run:
```bash
node -v  
```


## Installation

To install **Forster Portfolio (4sta)** globally, make sure you have Node.js (v16 or later) installed, then run:

```bash
npm install -g 4sta
```
Once installation is complete, launch the portfolio by typing:
```bash
4sta
```

## Navigation Guide

Once launched, you can explore the entire portfolio using only your keyboard:
⬆️ / ⬇️ Arrow Keys: Move through the sidebar menu
Enter: Open the selected page
While on a page:
Press Enter again to expand or collapse content
b: Move back to the sidebar

Ctrl + C: Exit the application

Each page renders dynamically, creating a smooth and interactive terminal experience. Explore sections like About, Skills, Projects, Experience, and Contact — all in one clean CLI interface.
